# 宇宙之主

一款科幻题材的策略养成 Web 游戏。玩家从 **1 级星球执政官**起步，通过完成任务积累经验，
一路晋升到 **100 级宇宙之主**，体验一整套架空的宇宙官场职位体系与晋升路径。

## 玩法要点

- **职位晋升**：1 级起步，100 级封顶，中间是一整套品级台阶——
  从九品 → 从一品 → 正一品 → 超品上卿，一级级往上爬。
- **治理层级**：行星基层管理 → 星系管理层 → 星云管理层 → 星域管理层 → 宇宙最高层，
  每一层都有对应的政务与事件。
- **资源体系**：
  - **星币** —— 通用货币，用于日常开支与打通关节
  - **暗能水晶** —— 稀缺资源，高阶晋升和特殊任务的硬门槛
  - **政绩经验** —— 完成任务获得，决定晋升速度
- **政务任务**：基层词讼、星区贪腐等各类事件，处置方式会影响政绩与声望。

## 技术说明

- 打包后的 React 单页应用，仓库内只有三个文件：`index.html`、`app.js`、`app.css`。
- 无后端、无网络请求，进度存在浏览器本地。
- 界面为深色主题。
